# ORJI POOSH — اورجی پوش

A Persian RTL fashion storefront built with HTML, CSS and vanilla JavaScript.

## Preview locally
Open `index.html` in a browser, or serve this folder with any static web server.

## Included
- Responsive Persian RTL storefront with editorial homepage
- Women's, men's and accessories collections
- Product cards, filters and search
- Product detail modal with size selection
- Client-side cart persisted in localStorage
- Newsletter interaction placeholder
- Render static-site deployment blueprint

## Production checklist
This repository currently contains a front-end storefront and sample catalog. It is not yet connected to a backend, live inventory, customer accounts, shipping, or a payment gateway. Replace sample product data and connect a secure backend/payment provider before accepting real orders. Never collect card details directly in this static frontend.

## Deploy
Deploy as a static site on Render or GitHub Pages. The included `render.yaml` defines a Render static site.
